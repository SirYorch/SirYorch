### Computer Vision System for Snoezelen Environments

**YOLO11 · Python · Blender · Distributed Computing**

Development of an object detection system for synthetic Snoezelen environments.

- Generation of approximately **141,000 synthetic images**.
- 3D environment modeling using Blender.
- Simulation of different lighting conditions for dataset generation.
- Distributed model training using a cluster of **20 computers**.
- Implementation of shared storage and parallel computing workflows.

### Research Web Platform

**Angular · Django · PostgreSQL · Docker · Linux**

Full-stack development of a research management platform.

- Frontend architecture and development with Angular.
- Backend development using Python and Django.
- PostgreSQL database design and administration.
- Containerized deployment using Docker.
- Linux server configuration and service administration.

Interactive educational application designed for children aged 7–10.
